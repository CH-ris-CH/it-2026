# Курс "Интернет-технологии"

- Результат: техническое задание (1 семестр) и его реализация (2 семестр).

- Группы делятся на проектные команды не более 3-х человек. Желающие могут выполнять работу самостоятельно, т.е. группа может состоять из одного человека.

- Проектная команда выбирает проект, который она будет реализовывать.

- Группы делятся на презентационные команды не более 2-х человек. Желающие могут выполнять работу самостоятельно, т.е. группа может состоять из одного человека.

- Презентационная команда выбирает тему презентации и проводит ее.

## Командная работа (проект)

Результат первого семестра - набор артефактов:

- 01-Заказчик
  - Видение
- 02-Бизнес-аналитик
  - Бизнес-процессы
  - Пользовательские истории
  - Термины
- 03-Системный аналитик
  - Модель предметной области
  - Варианты использования
  - Сценарии
  - Нефункциональные требования
- 04-Дизайнер
  - Пользовательский интерфейс
  - Навигация
  - Компоненты пользовательского интерфейса - опционально
  - Верстка (html, css) - опционально
- 05-Архитектор БД
  - Логическая схема
  - Физическая схема
  - Описание БД
  - SQL-скрипты (create, test, query) - опционально
- 06-Архитектор ПС
  - Компонентная модель
  - Архитектура
  - Потоки данных

- Структура git-репозитория. Например, для команды **01** структура директорий следующая:
- project\01\
  - \01-Заказчик
    - \data - картинки и т.п.
    - Видение.md (или *.pdf)
  - \02-Бизнеc-аналитик
    - \data - картинки и т.п.
    - Бизнес-процессы.md (или *.pdf)
    - Пользовательские истории.md (или *.pdf)
    - Термины.md (или *.pdf)
  - ...

На каждом занятии происходит проверка артефактов (по готовности, но с deadline).

Оценка командной деятельности - коллективная.

## Командная работа (презентация)

Все презентации сохраняются в git-репозитории. Например, для темы **Tailwind** команды **01** структура директорий следующая:

- presentation\01-Tailwind\
  - src\ - исходный код, который используется в презентации
  - Tailwind.pdf - pdf-версия презентации
  - readme.md - содержание каталога

По презентациям могут быть заданы вопросы, на которые нужно дать ответ. Вопросы можно задавать, как на занятиях, так и после них.

## Правила выставления оценок

За курс можно получить максимум 100 баллов, которые соответствуют оценкам:

- 91-100 - отлично
- 71-90 - хорошо
- 51-70 - удовлетворительно
- менее 51 - неудовлетворительно

Баллы начисляются:

- проектная работа: от 0 до 70
- презентационная работа: от 0 до 30
- активная жизненная позиция: от 0 до 10

Обязательное условие получения положительной оценки - прохождение электронного курса по UML (на OpenEDU)
